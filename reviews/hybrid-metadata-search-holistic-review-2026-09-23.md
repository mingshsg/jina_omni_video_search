# Hybrid metadata search — holistic review, 2026-09-23

Scope: current uncommitted hybrid feature on `live-video-search`, plans, prior reviews and follow-up trackers, with focused inspection of Suggest → Save → indexed search and the optional semantic/parser paths. This does not replace the dated phase reviews. No indexed record or deployment was mutated for this review.

**Verdict: functional local hybrid/search and edit-time Suggest exist, but the feature is not ready for end-to-end sign-off or internet enrichment.** The Phase 1/2 and Phase 3–3.6 code fixes are recorded in `todo/05`, `todo/06`, and `todo/11`; their integration, representative relevance, latency, browser, and configured EIS/semantic gates remain open. All eight Phase 4 findings in `todo/14` remain open. The earlier Docker rebuild proved route/UI availability on 26 assets, not quality or the current worktree's runtime state.

## Current information flow

`POST /api/library/{videoId}/meta/suggest` (`app/api/library/[videoId]/meta/suggest/route.ts:45-115`) reads the saved title via Elasticsearch, combines it with the editor's current empty fields and optional caller-supplied language, then invokes only `buildLocalSuggestions` (`lib/metadata/suggest-local.ts`). It returns `provider: local`; there is no Jina Search/Reader, remote catalog, MCP connector, Agent Builder agent or text generation in this path. The separate `JINA_API_KEY` configuration is used by an optional embedding provider, not web research. The EIS query parser handles search text, not internet lookup. Suggest alone does not save; the editor's later PATCH can index description/abstract for BM25 and a separate semantic asset vector.

## Findings and gaps, ordered by impact

1. **P1, already tracked F4-01–F4-04:** Boilerplate caveats can become indexed description/abstract and false search evidence; suggestion value/provenance updates are not atomic; the next Save can relabel unchanged suggestions as manual; a hung Suggest blocks Save. See `reviews/hybrid-metadata-search-phase4a-4b-review-2026-09-22.md` and the post-rebuild review. Close these before adding network latency or richer generated text.
2. **P1, additional lifecycle risk:** `lib/es/asset-meta.ts:270-295` starts description embedding as a detached async task after PATCH. `Promise.race` after eight seconds neither cancels the provider call nor durably schedules retry. A process exit can strand a stale vector, and an unbounded provider call may continue after the race. `lib/metadata/description-embed.ts:130-151` returns `published` even when the revision guard no-ops during a concurrent edit. The status is then not reliable evidence that the current text is searchable. Use a durable reconciliation job or explicit stale scan, inspect the ES update result, retry on version drift, and bound/cancel the actual provider operation. Keep this separate from the Suggest rollout.
3. **P2, already tracked F4-05–F4-08:** Per-field evidence is discarded in the editor and storage, filename cleanup retains noisy numeric prefixes and can remove title words, the library sample has no labeled correctness audit, and client-supplied language can be misrepresented as a verified media tag. These gaps directly impair external matching and human review.
4. **P2, missing external-source boundary:** A future web result will identify a *work*, not this uploaded *file*. A movie synopsis, release year, cast, and origin must be labeled work-level and must not imply that a trailer/interview/clip contains a scene or actor. Require a candidate-selection state for ambiguous titles and field-specific citations; abstain when title/year/type disagree. Do not copy a publisher's synopsis into indexed text without checking reuse terms.
5. **P2, operational boundary before enabling web calls:** The current Suggest route has no authentication, request-cost limit, timeout, URL/source allowlist, or error-safe upstream wrapper because it only performs local inference. Internet/agent calls must be opt-in, server-only, rate-limited, bounded and safely handled, especially if the demo is reachable beyond localhost. `app/api/library/[videoId]/meta/suggest/route.ts:106-112` reflects arbitrary error messages to clients with only a narrow `ApiKey` redaction pattern; external-provider errors need a generic public code and internal sanitized diagnostics.
6. **Acceptance remains open:** `todo/05`, `todo/06`, and `todo/11` still require live instance/schema/editor/index integration, filter size and latency, enabled EIS/semantic checks, labeled Recall@5, and broad browser/file/image/live regression. The new search UI polish (`todo/15`) is not a substitute for those gates. A green unit suite or rebuilt container is a narrower claim.

## Internet and Agent Builder disposition

Recommend a staged title-first flow detailed in `plan/04-internet-grounded-metadata-suggest.md`: deterministic title cleanup → candidate catalog search → human disambiguation → source-backed drafts; optional Jina web search + read for missing/ambiguous catalog evidence; optional Agent Builder agent for constrained multi-source research, never for the core search request. Agent Builder currently documents remote MCP tools and custom skills, but deployment entitlement, outbound connector access, Jina authentication/tool health, model availability and latency must be probed on this instance. The existing Jina skill's July tool list is stale against the current official MCP repository (which documents removed parallel/utility tools); import only `search_web` and `read_url` after `listTools`.
